Privacy policy — TubeEarn

Last updated: 6 October 2026

TubeEarn is a personal tool run by a single channel owner to manage their own YouTube channels (When We Were Few and Quand Nous Étions Peu). It is not used by, or offered to, anyone else.

What it accesses

With the owner's consent through Google OAuth, TubeEarn uses the YouTube Data API and the YouTube Analytics API to upload the owner's videos, update their metadata, thumbnails, captions and playlists, and read the owner's channel statistics.

What it stores

OAuth tokens are stored only on the owner's computer. Channel statistics are written to local reports on that computer. No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

TubeEarn's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
